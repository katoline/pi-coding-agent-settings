# 008: サンドボックスは Pi の公式のものを使う(具体的な方式は要確認)

- 日付: 2026-11-13
- 状態: 方針は決定。具体的な方式は暫定(確認待ち)

## 背景
作業を止めないために、サンドボックスを導入したい。Pi には組み込みのサンドボックスがない。ユーザーは「Pi が公式で出しているものがあれば、それを使ってよい」と判断した。

## 決定
- Pi の公式のものを使う。
- **訂正:** 公式の `sandbox/` サンプル(bubblewrap + sandbox-runtime)は、**Pi 1.5.0(2026-11-02)で削除済み**。ユーザーの判断は、この古い情報(0.81.1 のドキュメント)に基づいていた。
- 現在の公式の選択肢は、Gondolin 拡張(マイクロ VM)、Docker、Docker Sandboxes、OpenShell(Pi 1.5.2 の docs/containerization.md)。
- **暫定の第一候補は Gondolin 拡張**(ホストの Pi のまま、ツールだけを VM に流す)。第二候補は素の Docker。詳細は sandbox-options.md。

## 確認が必要な点(未確認)
1. プロジェクトの検証コマンドと Nix の環境を、ゲストの中で動かせるか(ゲストは Alpine ベース。公式の方式はいずれも「ホストとは別の環境」)
2. Gondolin は「実験的」と明記されている
3. VM の中のコマンドは、ホストの環境変数を引き継ぐ(API キーの渡し方に注意)
4. Linux で `/dev/kvm` が使えるか(使えれば QEMU は不要。使えなければ QEMU が必要)
5. サブエージェント(子プロセス)も隔離するには、子にも同じ仕組みを効かせる必要がある

## 却下した案
- なし(コミュニティ製の OS サンドボックスは、公式でないため後回し。ホストの道具をそのまま使える利点があり、1 が解決できない場合の代替)
