# 010: 設定リポジトリを katoline/pi-coding-agent-settings に紐付け、全面的に刷新する

- 日付: 2026-11-13
- 状態: 決定(進め方の詳細は確認待ち)

## 背景
設計の会話セッションを、GitHub のリポジトリ katoline/pi-coding-agent-settings に紐付けた。このリポジトリの既存の内容(旧設計。Pi 1.3.0、Docker ランチャー、bash 禁止、AGENTS.md による方針、マージしない)は古く、今の要件と方針が逆の部分も多い。

## 決定
- 設計資料(これまでの決定記録、評価、調査)は、このリポジトリの `docs/` を正本とする。以後の記録もここに書く
- 旧設計は土台にしない。**全面的に作り直してよい**(ユーザーの指示)
- 刷新計画は docs/repo-redesign-plan.md。コードの置き換えは、サンドボックスの方式と自律ループの調査結果を待って着手する
- 作業用ブランチは `redesign/v2`(旧設計のブランチ `agent/bootstrap-harness` から作成)

## 理由
- 旧設計は「bash 禁止、AGENTS.md に方針、マージしない」で、新しい要件(bash を許可してサンドボックスで守る、ハーネスで強制する、CI が通ったら自動マージ)と逆
- 旧設計の優れた部分(親子の環境変数、子の起動引数、委譲の上限、検証済みツリーだけをコミットする仕組み、テストの方式)は、考え方・コードの一部として引き継ぐ(刷新計画の 3 節)

## 却下した案
- 旧設計を土台に、差分を直していく案(ユーザーが、全面的に変えてよいと判断)

## 未解決事項
