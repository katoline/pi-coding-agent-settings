# 003: Pi の使い方は「人が TUI で対話」を当面の主軸とする

- 日付: 2026-11-13
- 状態: 決定

## 背景
Pi には TUI / print-JSON / RPC / SDK の 4 モードがある。どれを主に使うかを決める必要があった。

## 決定
- 当面は、人が TUI で対話して使う
- 別の PC からのリモート利用は、ノート PC のターミナルから Tailscale 経由でデスクトップ PC に接続し、接続先で Pi の TUI を開く方式とする
  - この接続環境はすでに構築済み。設計の対象外とする
- 他のエージェントから呼び出す用途(下記)は、今は検討しない

## 理由
ユーザーの利用形態。TUI を人が使うだけなら、設計の中心はモード選択ではなく、プロバイダ設定やハーネスの設定(拡張、skills、プロンプト)になる。

## 却下した案
なし(RPC / SDK / print-JSON は将来の検討に回す)

## 将来メモ(今は検討しない)
- Meta の Muse や Grok のボットなど、他のエージェントから Pi を呼び出せるようにしたい
- その場合に使うのは、print/JSON、RPC、SDK のモードの可能性が高い(要調査)

## 未解決事項
なし
